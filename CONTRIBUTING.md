# Contributing

This repository holds a published study. It is not a project that takes new features.

## What helps

- A paper that contradicts a verdict, with the sentence quoted. Use the issue form "A paper contradicts a verdict".
- An error in a table row or a sentence on the page, with the evidence. Use the issue form "Something in the data or the page is wrong".
- A broken link.

## How a report is handled

The maintainer checks it against the tables and against the paper. A confirmed error is fixed in the next edition of the page and the tables, and the fix is noted there. A report that cannot be checked, for example one without the paper's sentence, stays open until it can.

## What is not accepted

- Edits to the tables by pull request without the paper evidence.
- Any direct edit of a table, even with evidence. The tables are generated, so a correction is applied at the source and the tables are produced again.

## Response times

No promise is made about how fast a report is answered.

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions to the text and data are under the licence in [`LICENSE.md`](LICENSE.md).
